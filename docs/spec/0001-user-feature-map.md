# Features by User

This document lists all the actions that they user type should have access to within the application.  

## User 1 - The Totally Anonymous User
- View the homepage
- View contact page
- View about page
- Create an account
- Create a board
- View board
- Board
  - Edit board title
  - View votes remaining
  - View indicators for Attribution, Hide Others’ Notes, Notes Locked, and Voting settings
  - See message to log in and claim the board
  - Columns
    - Edit column titles
    - Delete column
    - Prompt Text
      - Add prompt text to column
      - Edit prompt text
      - Delete prompt text
    - Notes
      - Add Note
      - View notes
      - Edit Note
      - Delete Note
      - Drag/Drop notes between columns
      - Like Note
      - Upvote Note
      - Undo vote - Reclaim a vote
    - Action Items
      - Add an action item
      - View action items
      - Edit action item
      - Check off action item
      - Delete action item
      - View progress of action items
  - Command Deck
    - Start timer
    - Cancel timer
    - Add a column
    - Sort by likes
    - Attach files
    - User Attribution (guest only if all anonymous?)
    - Hide/Show action items
    - Hide Others’ Notes
    - Enable Voting
    - Lock Notes
    - Lock Board
    - Export CSV
    - Export MD
    - View note count
    - View contributor count - user who adds a note
    - View voter count - user who has cast a like/vote on a note
    - Collapse the command deck to get it out of the way
    - Expand command deck to see all the controls
    - View the command deck on all anonmymously owned boards even when not the owner

## User 2 - The User with a Registered Account
- Log in
- Log out
- Set user preferences
  - light or dark mode
- View Dashboard page
  - View a sidebar menu with links to:
    - The Dashboard Page
    - The crews page
    - The Personal team page
  - Action Items
    - View a list of all open action items from boards in the personal team
    - Add a team level action item
    - Edit action items
    - Delete action items
    - Check off action items
  - Boards
    - View a list of all boards owned by the logged in user (title, crew, role, action items count, created, updated)
    - Filter boards by text
    - sort boardy by Recently updated, recently created, or Title
    - Create a new board
    - Claim an anonymous board by pasting the link to it into a form
    - Duplicate a board - keeping all settings and columns but no content
    - Archive a board
    - Delete a board
    - View a list of all archived boards owned by the logged in user (Title, Crew, Role, Actions Items count, created, date archived)
    - Un-archive a board

## User 3  - Paid User account
- Crew Access
  - Create Crew
  - View Crew page
  - Delete Crew
  - Update Crew Name
  - Add Crew Members
  - Delete Crew Members
  - Add AI Member - Generate API Key
  - View AI Members - API Keys
  - Delete AI Member - Delete API Key

## User 4 - Site Admin
- Admin Dashboard
  - View statistics on the page
  - Create new site admins
  - View site admins
  - Delete site admins
